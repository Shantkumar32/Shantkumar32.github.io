Networking Fundamentals

Learn networking concepts for Cyber Crime Investigation

1. What is a Computer Network?

A computer network is a group of devices connected together to communicate and exchange data.

2. IP Address

An IP address identifies a device or network interface on an IP network.

Example IPv4: 192.168.1.10

Example IPv6: 2001:db8::1

3. TCP and UDP

TCP is connection-oriented and provides reliable, ordered delivery of data.

UDP is connectionless and generally has lower overhead than TCP.

4. Network Ports

A port helps identify a service or application endpoint associated with network communication.

Examples:

  • Port 53 – commonly DNS
  • Port 80 – commonly HTTP
  • Port 443 – commonly HTTPS
  • Port 123 – commonly NTP

5. DNS

DNS (Domain Name System) translates domain names into IP addresses and supports other DNS records.

Example: example.com → IP address

6. HTTP and HTTPS

HTTP is commonly used for web communication. HTTPS uses TLS to protect HTTP traffic in transit.

7. Public and Private IP Addresses

Private IP addresses are used within private networks. Public IP addresses can be used for communication across the public Internet.

8. Networking in Cyber Crime Investigation

Network information can help investigators understand communication paths and identify relevant technical information such as IP addresses, ports, timestamps, protocols and service providers.

Such information should be interpreted together with timestamps, subscriber records, logs and other evidence.
